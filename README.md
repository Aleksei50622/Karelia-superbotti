# Karelia-superbotti
Karelia-superbotti projekti

NetCordiin pohjautuva Discord botti joka käyttää LocalAI:ta erilaisiin komentoihin

Käyttö vaatii seuraavaa:
	1.Discord botin tokeni määritetty appsettings.json tiedostossa
	2.LocalAI kontti päällä määritetyssä hostissa
	3.Chatti ja TTS modelit valmiina LocalAI:ssa
